Preprocessing#

langkah untuk mengubah data mentah menjadi lebih terstruktur dan siap diolah dengan model

Preprocessing yang dilakukan:

  • Cleaning :

    Membersihkan teks dari karakter tidak relevan seperti tanda baca, angka, atau simbol.

    Contoh:

    Teks asli: “Saya sedang belajar pemrograman di rumah!”

    Setelah cleaning: “Saya sedang belajar pemrograman di rumah”

  • Case Folding

    Mengubah seluruh teks menjadi huruf kecil

    Contoh:

    “Saya Sedang Belajar Pemrograman” menjadi “saya sedang belajar pemrograman”.

  • Tokenize

    Memecah teks menjadi unit terkecil, seperti kata atau kalimat.

    Contoh:

    Teks: “saya sedang belajar pemrograman di rumah”

    Setelah tokenisasi: ["saya", "sedang", "belajar", "pemrograman", "di", "rumah"]

  • Stop Word Removal

    Menghapus kata-kata umum yang tidak memiliki makna signifikan dalam analisis, seperti “di”, “yang”, atau “dan”.

    Contoh:

    Token: ["saya", "sedang", "belajar", "pemrograman", "di", "rumah"]

    Setelah stop word removal: ["belajar", "pemrograman", "rumah"]

  • Stemming

    Mengubah kata menjadi bentuk dasarny.

    Contoh:

    Token: ["belajar", "pemrograman", "rumah"]

    Setelah stemming: ["ajar", "program", "rumah"]

TFIDF#

TF-IDF (Term Frequency-Inverse Document Frequency) adalah metode yang digunakan untuk menentukan seberapa penting sebuah kata dalam suatu dokumen dibandingkan dengan dokumen-dokumen lainnya. Metode ini menggabungkan dua hal: Term Frequency (TF), yaitu seberapa sering kata muncul di dalam sebuah dokumen, dan **Inverse Document Frequency (IDF), yang menunjukkan seberapa jarang kata tersebut muncul di seluruh kumpulan dokumen. Dengan begitu, kata yang sering muncul di dokumen tetapi jarang ada di dokumen lain dianggap lebih penting.

# TF-IDF vectorizer

SVD#

Singular Value Decomposition (SVD)#

SVD adalah teknik matematika yang digunakan untuk memecah atau mendekomposisi sebuah matriks menjadi tiga matriks lain. Matriks-matriks ini dapat membantu kita memahami struktur data atau memproses data lebih lanjut, seperti dalam reduksi dimensi, pengolahan gambar, atau sistem rekomendasi.

Komponen SVD#

Jika kita memiliki sebuah matriks A dengan ukuran ( m \times n ), SVD mendekomposisinya menjadi tiga matriks berikut:

[ A = U \Sigma V^T ]

  1. Matriks ( U ):

    • Ukuran ( m \times m ).

    • Berisi vektor-vektor ortogonal yang dikenal sebagai left singular vectors.

    • Merepresentasikan pola pada baris matriks ( A ).

  2. Matriks ( \Sigma ):

    • Ukuran ( m \times n ).

    • Matriks diagonal yang berisi singular values dalam urutan menurun.

    • Nilai-nilai ini menggambarkan kontribusi atau kekuatan masing-masing dimensi.

  3. Matriks ( V^T ):

    • Ukuran ( n \times n ).

    • Berisi vektor-vektor ortogonal yang dikenal sebagai right singular vectors.

    • Merepresentasikan pola pada kolom matriks ( A ).

# Dimensi untuk SVD
dimensions = [50, 75, 95]
models = {}

# Latih model untuk setiap dimensi
for dim in dimensions:
    print(f"Training model dengan {dim} dimensi...")
    svd = TruncatedSVD(n_components=dim, random_state=42)
    X_train_svd = svd.fit_transform(X_tfidf)

    # Simpan model SVD ke file
    svd_filename = f'svd_model_{dim}.pkl'
    with open(svd_filename, 'wb') as f:
        pickle.dump(svd, f)

    # Logistic Regression Model
    model = LogisticRegression()
    model.fit(X_train_svd, Ytrain)

    # Simpan Logistic Regression model ke file
    model_filename = f'logistic_model_{dim}.pkl'
    with open(model_filename, 'wb') as f:
        pickle.dump(model, f)

    # Evaluasi model
    X_test_tfidf = vect.transform(Xtest)
    X_test_svd = svd.transform(X_test_tfidf)
    prediksi = model.predict(X_test_svd)
    accuracy = accuracy_score(Ytest, prediksi)
    print(f"Akurasi untuk {dim} dimensi: {accuracy * 100:.2f}%")
    models[dim] = accuracy

# Menampilkan hasil akhir
for dim, acc in models.items():
    print(f"Akurasi model dengan {dim} dimensi: {acc * 100:.2f}%")

def preprocess_input(text):
    text = remove_symbols(text)
    text = case_folding(text)
    tokens = tokenize(text)
    tokens = remove_stopwords(tokens)
    tokens = stemming(tokens)
    return ' '.join(tokens)

# Fungsi untuk memprediksi kategori
def predict_category(user_input, dimension):
    # Load TF-IDF vectorizer
    with open('tfidf_vectorizer.pkl', 'rb') as f:
        tfidf_vectorizer = pickle.load(f)

    # Load SVD model
    svd_filename = f'svd_model_{dimension}.pkl'
    with open(svd_filename, 'rb') as f:
        svd_model = pickle.load(f)

    # Load Logistic Regression model
    model_filename = f'logistic_model_{dimension}.pkl'
    with open(model_filename, 'rb') as f:
        logistic_model = pickle.load(f)

    # Preprocess user input
    preprocessed_input = preprocess_input(user_input)

    # Transform input
    input_tfidf = tfidf_vectorizer.transform([preprocessed_input])
    input_svd = svd_model.transform(input_tfidf)

    # Predict
    prediction = logistic_model.predict(input_svd)
    category_map = {0: 'Politik', 1: 'Gaya Hidup'}
    return category_map[prediction[0]]
